# Nova Echo AI — Concept Redesign

Portfolio case study by **Eloisa Jane Talingting**. Concept redesign of [novaecho.ai](https://novaecho.ai), not affiliated with or endorsed by Nova Echo AI.

Built with **Next.js (App Router)**, **Tailwind CSS 4**, and **GSAP**.

## Features

- Dark/light section rhythm with a custom design system
- Speech-driven animated waveform background (hero)
- Fully responsive — mobile-first, desktop at 1024px+
- ROI calculator modal in the Agents section
- Smooth scroll navigation with active section tracking
- Animated mobile menu with staggered link reveals

## Design System

See [`design.md`](./design.md) for the full source of truth — colors, typography, spacing, gradients, motion tokens, and component specs.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command    | Description            |

| `npm run build` | Production build    |
| `npm run start` | Start production server |
| `npm run lint`  | Run ESLint          |

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript (strict)
- **Styling:** Tailwind CSS 4
- **Animation:** GSAP 3 (ScrollTrigger, motion hooks)
- **Icons:** Phosphor React
- **Fonts:** Plus Jakarta Sans (display), Inter (body)
